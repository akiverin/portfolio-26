# andkiv · «Обо мне» · пять направлений

Статические дизайн-концепты в продолжение Hero «Ясный проход». Рабочая секция сайта не изменена.

- [Полные промпты встроенного image_gen](prompts.md)

1. **Береговая редакция** — светлый журнальный разворот, личный портрет, открытая сетка компетенций.
2. **Синяя мастерская** — тёмная студия, инженерная структура, сочетание дизайна и разработки.
3. **Личный архив** — коллаж из фотографии, заметок и ASCII-слоёв.
4. **Траектория** — образование и практика как маршрут по цифровому берегу.
5. **Человек и система** — тёплый типографический манифест и три принципа работы.

Для генерации использованы текущий Hero, существующая фотография автора и утверждённый объёмный маскот. Промпты содержат реальные сведения из секции About. Сгенерированные изображения показывают композицию и стиль; мелкий текст, подписи и детали при реализации следует брать из актуальных данных сайта. Оригиналы сохранены в исходном разрешении без увеличения.

Повторная сборка галереи и листа сравнения: `rtk proxy python3 assets/about-explorations/round-01/prepare-gallery.py` (Pillow).
