# andkiv · ASCII cinema

Пять вариантов первого Hero-концепта. Синий амбассадор, кинематографическая сине-оранжевая палитра, разные ASCII-пейзажи и тексты. Имя автора остаётся небольшой подписью.

- [Галерея: изображения, тексты и идеи движения](gallery.html)
- [Общий лист для сравнения](contact-sheet.jpg)
- [Точные промпты встроенного image_gen](prompts.md)
- [Тексты, палитры и размеры](manifest.json)
- `concepts/` — оригиналы генератора.
- `exports-4k/` — PNG 3840 × 2160.
- `references/` — выбранный первый концепт и синий вариант существующего SVG-персонажа.

Генератор вернул оригиналы в разрешении меньше запрошенного 4K. Экспорты увеличены Lanczos до 3840 × 2160; это **не нативная 4K-генерация**. Исходники не заменены и не ретушировались. Точные исходные размеры и метод экспорта записаны для каждого файла в manifest.json.

Идеи параллакса описаны для следующего этапа. Здесь статические концепты: код сайта и действующие брендовые ассеты не изменены.

Пересобрать галерею, лист сравнения и экспорты (Python + Pillow):

```sh
rtk proxy python3 assets/hero-explorations/ascii-cinema-4k/prepare-previews.py
```
