# andkiv — восемь вариантов Hero

Изображения для выбора направления обновления Hero сайта версии 2.1. Основа — присланные семь референсов и уже выбранный персонаж. Сайдбар сохранён как контекст; главная задача — сравнить композиции первого экрана.

## Направления и движение

### 01. Цифровой горизонт / ASCII Horizon

[Полноразмерное изображение](concepts/01-ascii-horizon.png)

Тёмный ASCII-пейзаж и крупная светлая типографика.

- **Появление:** Облака собираются из символов, имя проявляется вертикальной маской.
- **Параллакс:** Склоны сдвигаются сильнее дальних облаков; локальное поле символов реагирует на указатель.
- **Переход при скролле:** Ближний склон уходит вверх, типографика задерживается, фон растворяется в блоке обо мне.
- **Слои:** Дальний цифровой небосвод → Облака из символов → Типографика и CTA → Ближний склон из точек.
- **Подход к реализации:** Canvas с ограниченной плотностью символов и заранее подготовленными слоями; на мобильном меньше знаков.

### 02. Поток символов / Symbol Current

[Полноразмерное изображение](concepts/02-symbol-current.png)

Кобальтовое поле микро-стрелок с пустотой в форме персонажа.

- **Появление:** От центра расходится волна, формируя силуэт в поле знаков.
- **Параллакс:** Стрелки поворачиваются к курсору; чистая зона медленно смещается.
- **Переход при скролле:** Поле расходится по краям, открывая светлый следующий раздел.
- **Слои:** Кобальтовый градиент → Поле микро-стрелок → Негативный силуэт персонажа → Название и кнопки.
- **Подход к реализации:** Один Canvas с полем векторов; без отдельного DOM-элемента на каждый символ.

### 03. Небесная студия / Sky Studio

[Полноразмерное изображение](concepts/03-sky-studio.png)

Светлая небесная сетка, стеклянный andkiv и парящий персонаж.

- **Появление:** Стеклянные буквы мягко надуваются и ловят первый блик.
- **Параллакс:** Буквы, персонаж и облачные тени перемещаются с разной инерцией.
- **Переход при скролле:** Стеклянная надпись проходит за заголовком и уходит вверх.
- **Слои:** Небо и облачные тени → Тонкая редакционная сетка → Объёмный стеклянный andkiv → Парящий персиковый персонаж → Чёрная типографика.
- **Подход к реализации:** Предрендеренные прозрачные слои для лёгкой версии; WebGL только при необходимости динамических отражений.

### 04. Творческая лаборатория / Plum Laboratory

[Полноразмерное изображение](concepts/04-plum-laboratory.png)

Редакционный кремовый разворот и наклонные фиолетовые панели.

- **Появление:** Панели по очереди выдвигаются из глубины, подпись печатается строками.
- **Параллакс:** Рамки наклоняются на 2–4 градуса с разной глубиной.
- **Переход при скролле:** Передняя рамка расширяется в переход к проектам.
- **Слои:** Кремовая редакционная колонка → Фиолетовое поле глубины → Три наклонные рамки → Светлый персонаж внутри экспоната.
- **Подход к реализации:** CSS perspective и transform для трёх панелей; персонаж отдельным прозрачным слоем.

### 05. Живой цифровой сад / Living Garden

[Полноразмерное изображение](concepts/05-living-garden.png)

Фотореалистичная трава и кремовая типографика с цифровым персонажем.

- **Появление:** Свет постепенно открывает траву, имя появляется спокойным вертикальным движением.
- **Параллакс:** Передние стебли дают ощутимую глубину; персонаж мягко следует за курсором.
- **Переход при скролле:** Трава расходится, кремовая волна открывает следующий раздел.
- **Слои:** Дальний мягкий холм → Средняя трава и цветы → Имя и действия → Ближние расфокусированные стебли → Персонаж из молочного стекла.
- **Подход к реализации:** Отдельные растровые планы травы, дальнего пейзажа и персонажа; небольшой диапазон движения.

### 06. Окно в цифровой мир / Window to Work

[Полноразмерное изображение](concepts/06-window-to-work.png)

Кинематографичная рама окна и пейзаж с глубиной.

- **Появление:** Свет проходит по кромке окна, открывая имя и пейзаж.
- **Параллакс:** Окно остаётся почти неподвижным; поле, горы и облака двигаются с разной скоростью.
- **Переход при скролле:** Камера приближается к окну и проходит в следующий раздел.
- **Слои:** Ближняя архитектура окна → Пейзаж и поле → Горы и облака → Текст на стекле → Маленькая наклейка персонажа.
- **Подход к реализации:** Раздельные окно, поле, горы и облака; переход приближением должен сохранять читаемость текста.

### 07. Синий дизайнерский коллаж / Blue Scrapbook

[Полноразмерное изображение](concepts/07-blue-scrapbook.png)

Редакционный кобальтовый коллаж с реальными облаками и бумажными слоями.

- **Появление:** Листы раскладываются с небольшим поворотом; заголовок появляется крупными блоками.
- **Параллакс:** Поляроиды получают разную инерцию и глубину, тонкие линии слегка отстают.
- **Переход при скролле:** Коллаж собирается в ровную сетку проектов.
- **Слои:** Молочная бумага и сетка → Крупная типографика → Поляроид с облаками → Перекрывающий лист и графический росчерк → Малый знак персонажа.
- **Подход к реализации:** Слои фотографий, бумаги и SVG-росчерка; трансформации и общая пружинная инерция.

### 08. Бумажный театр / Peach Paper Theatre

[Полноразмерное изображение](concepts/08-peach-paper-theatre.png)

Персиковая бумажная сцена с прорезями в форме персонажа.

- **Появление:** Бумажные слои раскрываются один за другим, показывая персонажа в глубине.
- **Параллакс:** Три силуэтных выреза смещаются навстречу друг другу, создавая бумажный параллакс.
- **Переход при скролле:** Передний бумажный слой поднимается шторой в следующий блок.
- **Слои:** Ближняя кремовая бумага → Персиковая рамка силуэта → Сливовая внутренняя рамка → Глубокая светлая сцена → Типографика перед сценой.
- **Подход к реализации:** Силуэтные SVG-слои с мягкими тенями; движение небольшое, чтобы бумажная форма сохранялась.


## Файлы

- `concepts/` — восемь исходных PNG, созданных image_gen.
- `contact-sheet.png` — все восемь концептов с номерами.
- `contact-sheet-01-04.png` и `contact-sheet-05-08.png` — более крупные листы сравнения.
- `gallery.html` — автономная галерея без зависимостей с описаниями движения.
- `references/` — сохранённые изображения-референсы.
- `manifest.json` — композиции, палитры, пути и сценарии движения.
- `prompts.md` — точные промпты всех восьми генераций.
- `prepare-previews.py` — воспроизводимая сборка листов; нужен Pillow.

Это статичные кадры концептов. Анимации и переходы пока описаны как сценарии; они не встроены в текущую Hero. При реализации выбранного варианта текст, кнопки, сайдбар и персонаж берутся из компонентов и SVG сайта. Для мобильной версии потребуется отдельная композиция, а при reduced motion — спокойное статичное состояние.

Мои кандидаты для дальнейшей проработки: **01** — эффектный цифровой пейзаж; **03** — светлая студийная подача; **08** — развитие собственного персонажа и персиково-сливовой палитры.
